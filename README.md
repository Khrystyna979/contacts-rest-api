# Contacts REST API
 
REST API для управління особистими контактами, реалізований на **FastAPI** та **SQLAlchemy 2.0 (async)**.
 
## Можливості
 
- Повний CRUD для контактів (створення, читання, оновлення, видалення)
- Пошук контактів за іменем, прізвищем або email
- Пагінація через параметри запиту `skip` / `limit`
- **Ендпоінт найближчих днів народження** — повертає контакти, у яких день народження настане протягом наступних N днів (коректно обробляє перехід через кінець року)
- Валідація даних через Pydantic, включно з перевіркою номера телефону українського формату
- Версіонування схеми бази даних через міграції Alembic
- PostgreSQL у Docker через `docker-compose`

## Технологічний стек
 
- **FastAPI** — веб-фреймворк
- **SQLAlchemy 2.0** (async) + **asyncpg** — ORM та драйвер бази даних
- **PostgreSQL** — база даних
- **Alembic** — міграції бази даних
- **Pydantic v2** — валідація даних та керування налаштуваннями
- **Docker Compose** — локальне середовище для бази даних
## Структура проєкту
 

## Швидкий старт
 
### Необхідні інструменти
 
- Python 3.13+
- [Poetry](https://python-poetry.org/) для керування залежностями
- Docker та Docker Compose
### Встановлення
 
1. Склонуй репозиторій:
```bash
   git clone https://github.com/Khrystyna979/contacts-rest-api.git
   cd contacts-rest-api
```
 
2. Скопіюй приклад файлу з налаштуваннями та за потреби зміни значення:
```bash
   cp .env.example .env
```
 
3. Запусти базу даних PostgreSQL:
```bash
   docker-compose up -d
```
 
4. Встанови залежності:
```bash
   poetry install
```
 
5. Застосуй міграції бази даних:
```bash
   poetry run alembic upgrade head
```
 
6. Запусти застосунок:
```bash
   poetry run uvicorn main:app --reload
```
 
API буде доступний за адресою `http://localhost:8000`.
Інтерактивна документація (Swagger UI): `http://localhost:8000/docs`
 
## Ендпоінти API
 
| Метод  | Ендпоінт                   | Опис                                          |
|--------|-----------------------------|------------------------------------------------|
| GET    | `/contacts/`               | Список контактів (з фільтрацією та пагінацією) |
| GET    | `/contacts/birthdays`      | Контакти з днем народження протягом N днів     |
| GET    | `/contacts/{contact_id}`   | Отримати контакт за ID                         |
| POST   | `/contacts/`               | Створити новий контакт                         |
| PUT    | `/contacts/{contact_id}`   | Оновити існуючий контакт                       |
| DELETE | `/contacts/{contact_id}`   | Видалити контакт                               |
